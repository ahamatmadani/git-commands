# Commands git
-liste de commandes git

## git init
-permet d'initialiser un repertoire 

## git add
-permet d'ajouter un fichier dans le stagging

## git commit
-permet d'enregister une modification en local
-le message est important

## git push
-permet de pousser les modifications en ligne

## git status
-permet de verifier le status du repertoire
-permet de lister les modifications a traiter

## git log
-permet de lister les modifications en local

## git branch
-permet de creer une branche`

## git checkout
-permet de passer d'une branche a une autre 
-permet aussi de se deplaver d'une branche a une autre 
-avec l'option -b checkout de creer la banesi elle n'existe pas 

## git pull
permet de recuperer les modifications distantes
